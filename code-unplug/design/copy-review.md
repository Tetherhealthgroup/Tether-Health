# Copy review pack

Every patient-facing string in this app that **nobody has reviewed**.

Two sources, and they need different reviewers:

- **Programme copy** — 223 strings across the 10 LookUp screens written in this
  repository (`assets/design/supplement.content.lookup.en.json`). These are read
  by a person in a health programme, several of them at their worst moment.
  They need clinical review. Each renders behind a "NOT CLINICALLY REVIEWED"
  notice until that happens.
- **Shell chrome** — 82 marked sites across the six host screens. These are
  navigation and control labels, not programme content, so most need an editor
  rather than a clinician. The exceptions are called out below.

Generated by `tool/extract_copy_review.py`. Regenerate after changing either source.
